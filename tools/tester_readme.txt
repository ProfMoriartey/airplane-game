RED ACE - test build
====================

Thanks for testing! This is an early build, so expect rough edges.

STARTING THE GAME
  Windows: double-click RedAce.exe.
    If Windows says "Windows protected your PC", click "More info", then "Run anyway".
    (The game isn't signed yet, so Windows doesn't recognise it.)
  Mac: right-click (or Control-click) "Red Ace", choose Open, then Open again.
    If the Mac says the app "is damaged" or "can't be opened", open Terminal and run:
      xattr -cr "/path/to/Red Ace.app"
    (Drag the app onto the Terminal window to fill in the path.)

CONTROLS
  Keyboard and mouse, or a controller / flight stick. Everything can be changed in
  Settings. Press Esc (or Start) to pause.

SENDING FEEDBACK
  After each mission, press "Feedback" on the results screen (or in the pause menu)
  and say how it felt. It only takes a few seconds.

  When you're done, go to Settings > Gameplay > "Open playtest folder", zip that
  folder and send it back. It holds your results and feedback - nothing personal.
  If the game crashed, please also send the folder from "Open log folder".
